# Fake Risk Score

Прототип аналитического инструмента для первичной скоринговой оценки риска фейковости русскоязычных текстов.

Проект разработан в рамках курсовой работы на тему:
"Аналитические инструменты выявления и противодействия фейковой информации в соцсетях".

## Назначение

Инструмент принимает на вход русскоязычный текст публикации или пару "заголовок + основной текст" и рассчитывает итоговый fake_score — числовую оценку риска подозрительности.

Результат не является окончательным доказательством фейковости. Он используется как инструмент первичной фильтрации публикаций, требующих дополнительной проверки.

## Архитектура

В прототип входят:

- NLI-модель для семантической оценки текста;
- NLI-модель для проверки противоречия между заголовком и основным текстом;
- модель определения эмоций;
- модель определения токсичности;
- собственный правиловый модуль;
- итоговая формула скоринга;
- модуль оценки качества на датасете.

## Используемые модели

- cointegrated/rubert-base-cased-nli-threeway
- cointegrated/rubert-tiny2-cedr-emotion-detection
- cointegrated/rubert-tiny-toxicity

## Данные

Датасет не загружается в репозиторий из-за размера и лицензионных ограничений.

Для запуска проекта необходимо скачать датасет Kaggle `Fake and real Russian news` и поместить файлы:

- `train_bodies.csv`
- `train_stances.csv`
- `test_bodies.csv`
- `test_stances_unlebeledb.csv`

в папку:

```text
data/raw/
```
Ссылка на скачивание датасета: https://www.kaggle.com/datasets/morfifinka/fake-real-news-ru?resource=download

## Запуск анализа одного текста, примеры

```powershell
python src/cli.py --text "Срочно! СМИ молчат! Очевидцы сообщают о катастрофе. Перешлите всем, пока это не удалили!!!"
```

## Запуск анализа пары "заголовок+текст"

```powershell
python src/cli.py --headline "Банк России повысил ключевую ставку" --body "Банк России сообщил о решении снизить ключевую ставку. Информация опубликована на официальном сайте регулятора."
```
