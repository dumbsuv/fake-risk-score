# Fake Risk Score

Прототип аналитического инструмента для первичной скоринговой оценки риска фейковости русскоязычных текстов. Разработан в рамках курсовой работы «Аналитические инструменты выявления и противодействия фейковой информации в соцсетях».

## Что делает

Принимает на вход текст публикации или пару «заголовок + основной текст» и возвращает `fake_score` — числовую оценку риска подозрительности. Результат не финальный вердикт, а инструмент первичной фильтрации: помогает быстро отсеять публикации, которые стоит проверить отдельно.

## Как это устроено

Итоговый скор собирается из нескольких независимых сигналов:

| Сигнал | Модель / метод |
|---|---|
| Семантическая оценка текста | `cointegrated/rubert-base-cased-nli-threeway` |
| Противоречие между заголовком и текстом | та же NLI-модель, отдельная пара вход-выход |
| Эмоциональная окраска | `cointegrated/rubert-tiny2-cedr-emotion-detection` |
| Токсичность | `cointegrated/rubert-tiny-toxicity` |
| Эвристики | собственный правиловый модуль |

Сигналы объединяются в единую формулу скоринга — итог, число, отражающее риск подозрительности текста.

## Установка

```bash
git clone https://github.com/dumbsuv/fake-risk-score.git
cd fake-risk-score
pip install -r requirements.txt
```

## Данные

Датасет не хранится в репозитории — слишком большой и с лицензионными ограничениями. Нужно скачать [Fake and real Russian news](https://www.kaggle.com/datasets/morfifinka/fake-real-news-ru?resource=download) с Kaggle и положить файлы `train_bodies.csv`, `train_stances.csv`, `test_bodies.csv`, `test_stances_unlebeledb.csv` в `data/raw/`.

## Использование

Анализ одного текста:
```bash
python src/cli.py --text "Срочно! СМИ молчат! Очевидцы сообщают о катастрофе. Перешлите всем, пока это не удалили!!!"
```

Анализ пары «заголовок + текст»:
```bash
python src/cli.py --headline "Банк России повысил ключевую ставку" --body "Банк России сообщил о решении снизить ключевую ставку. Информация опубликована на официальном сайте регулятора."
```

Оценка качества на выборке и подбор порога:
```bash
python src/evaluate.py --limit 100 --threshold 0.30
python src/tune_threshold.py
```

## Ограничения

Прототип обучен и протестирован на конкретном датасете русскоязычных новостей, обобщаемость на другие домены и типы текста не проверялась. `fake_score` — сигнал для дальнейшей проверки человеком, не окончательное решение о фейковости.
